# Security Policy

ParentVUE handles children's educational records and account credentials.

## Never include in public issues

- ParentVUE passwords
- session cookies or authentication tokens
- raw HAR captures
- full HTML/XML/JSON ParentVUE responses
- student IDs
- addresses, medical information, or emergency-contact information
- Synergy Mail/message contents
- report-card documents

For ordinary bugs, use the integration's privacy-preserving diagnostics and a
redacted Home Assistant traceback.

If a vulnerability could expose credentials or student records, do not open a
public issue containing exploit details. Contact the repository maintainer
privately using the security-reporting method published on the GitHub repository.
