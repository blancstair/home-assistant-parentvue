# ParentVUE

Home Assistant integration for Edupoint ParentVUE using the authenticated
ParentVUE website workflow.

Version 0.3.0 adds an entity-first data model and a configurable per-child
dashboard card for grades, schedules, attendance, missing assignments, and
available unread Synergy Mail status.

See `README.md` for setup, privacy, polling policy, and feature availability.
